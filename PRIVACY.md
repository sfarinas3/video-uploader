# Privacy Policy

video-uploader is a personal, locally-run tool with no server component
beyond the copy running on its author's own machine. It does not collect,
store, transmit, or share data about any user other than its author, and
it is not used by anyone other than its author.

OAuth credentials for connected platforms (YouTube, Facebook, Instagram,
TikTok) are stored locally in the operating system's own credential
store (via `keyring`) on the author's machine, never on a remote server.
Video files selected for upload are read from and processed on that same
local machine and sent directly to each platform's own API under the
author's own account.
